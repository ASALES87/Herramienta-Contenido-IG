# Workflows de GitHub Actions

Están aquí porque la carpeta `.github` no se puede escribir desde Claude (Cowork). Antes del primer envío a GitHub,
muévelos a `.github/workflows/` (los comandos están en el mensaje de Claude / LEEME principal).

- `publicar.yml`: publica en Instagram a las horas de los clientes (todos los clientes; simulación manual).
- `diario.yml`: comentarios nuevos (diario) e informe semanal (lunes) de cada cliente.
- `tokens.yml`: renueva los tokens de Instagram de cada cliente y avisa del GH_PAT (lunes y jueves).
- `contenido.yml`: aprueba tandas vencidas y avisa si a alguien se le acaba el contenido (cada mañana).
